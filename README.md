# Clio K4J

Ordinateur de bord OBD2 pour Clio 2 phase 2 (2001-2003), moteur K4J 1.4 16v.

Ouvrir https://huyx69.github.io/clio-k4j/ dans **Bluefy** (iPhone), contact mis, Car Scanner fermé, puis « Connecter le boîtier » → OBDBLE.

- Route : conso instantanée et moyenne (calculée par la pression d'admission), régime, eau, batterie, capteurs
- Diag : lecture et effacement des codes défaut moteur
- Pleins : calibration de la conso sur les litres réels de la pompe
- Trajets : historique, courbes, export CSV
